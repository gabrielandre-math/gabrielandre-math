# Gabriel André

**Backend Software Engineer** | C# .NET | AWS | Event-Driven Architecture | Rio de Janeiro, Brazil

I design and ship production backends end to end: domain modeling, APIs, messaging, infrastructure as code and deployment.

Deep technical solutions emerge from understanding the product, not just the code.

---

## What I'm building

- **Boatlux Hub** (BOATLUX): the company's corporate intranet, live in production. 22 integrated modules (work management, LMS, IT service desk, HR, asset management, sales CRM), 350+ API endpoints and 8 real-time SignalR channels. Modular monolith with Clean Architecture, DDD, CQRS, Outbox pattern and event-driven messaging (MassTransit + RabbitMQ/SQS) on AWS.
- **Meddie Pro** (Doctor Meddie, US HealthTech): core backend and AWS infrastructure for a secure clinical platform, provisioned as code.
- **e-Consulter** (HACK-CMP, Germany): full stack development in an international team of 28 people from 16 countries.

Before that, I led the migration of Java monoliths to .NET 8 services at BOATLUX and built Flutter apps with BLoC.
